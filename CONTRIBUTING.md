# Guide de Contribution — RFP Intelligence Engine

## Workflow Git & Pull Requests
1. Créer une branche dédiée depuis `main` (`feat/...`, `fix/...`, `docs/...`, `test/...`).
2. Vérifier la conformité du code avant tout commit :
   ```bash
   make lint
   make test
   ```
3. Soumettre une Pull Request documentée vers `main`.
